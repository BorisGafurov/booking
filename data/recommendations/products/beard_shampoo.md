# 🧼 Шампунь для бороды

Специально разработан для волос бороды, которые толще и жестче волос на голове, а также для чувствительной кожи лица.

**Рекомендуемый уход на Ozon:**
• [Специальное мыло для очищения бороды](https://ozon.ru/p/o8464506)

*Совет:* обычные шампуни для волос и гели для душа сушат кожу лица. Используйте специализированное очищение 2–3 раза в неделю.
