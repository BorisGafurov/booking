# ✂️ Telegram Booking & Referral Bot

Telegram-бот для онлайн-записи клиентов в салон и реферальной программы с начислением и списанием бонусов.

## 🚀 Стек технологий
- **Python 3.10+**
- **aiogram 3.x**
- **SQLite** (режим WAL, пул соединений)
- **python-dotenv**

---

## 📋 Основной функционал
- ✂️ **Онлайн-запись**: быстрая кнопка перехода к виджету онлайн-записи.
- 📍 **Геолокация и адрес**: отправка точки на карте и ссылки на Яндекс Карты.
- 🧴 **База знаний по уходу**: статьи и советы по укладке и бороде с удобной навигацией без спама в чате.
- 🎁 **Реферальная программа**:
  - Персональные ссылки `t.me/bot?start=ref_<id>`.
  - Уведомление реферера при регистрации друга.
  - Начисление бонуса после первого подтверждённого визита.
  - Просмотр статистики и баланса бонусов.
- ⚙️ **Админ-панель** (`/admin` или кнопка для админов):
  - Подтверждение визитов рефералов.
  - Списание бонусов в счёт оплаты с автоматическим уведомлением клиента.
  - Постраничная навигация (пагинация).

## 🛠 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd bot_booking
```

### 2. Создание виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate  # На Linux / macOS
# .venv\Scripts\activate   # На Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Заполните обязательные переменные:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
```

### 5. Запуск бота
```bash
python3 main.py
```
